# Mushroom Farm Dashboard (Vue 3 + Vite)

    npm install
    npm run dev

- ផ្ទាំង៖ Dashboard, វគ្គ, ផលិតកម្ម, ចំណូល, ចំណាយ
- ទិន្នន័យរក្សាក្នុង localStorage (key: `mushroom-farm-v1`) — ត្រូវគ្នានឹងទម្រង់នៃ artifact មុន
- ចង់ភ្ជាប់ Supabase៖ ជំនួស `state` ក្នុង `src/store.js` ដោយ fetch/insert ទៅតារាង batches, harvests, incomes, expenses
